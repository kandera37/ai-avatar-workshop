# Компоненты и атрибуция

| Компонент | Назначение | Лицензия пакета |
| --- | --- | --- |
| Express | HTTP-сервер и маршруты | MIT |
| better-sqlite3 | Доступ к SQLite | MIT |
| dotenv | Локальная конфигурация | BSD-2-Clause |
| Playwright | Автоматизация браузерных проверок | Apache-2.0 |
| Supertest | Проверка HTTP API | MIT |

Полные условия и уведомления входят в установленные npm-пакеты. Chromium для браузерных проверок устанавливается отдельно Playwright и распространяется на своих условиях.

Графический знак, схема архитектуры и обложка подготовлены для этого репозитория. Функциональные скриншоты сделаны с запущенного приложения; в них только синтетические ники и локальные тестовые изображения. Используются системные шрифты без включения файлов шрифтов в репозиторий.

Лицензия на исходный код приложения не назначена. Наличие публичного репозитория не означает выдачу открытой лицензии. Условия сторонних зависимостей не меняют условия приложения.
