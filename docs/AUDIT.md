## Два разных prompt-flow

Мастерская намеренно добавляет художественное направление BASE_PROMPT и правила аватара. Изменение BASE_PROMPT не отменяет обязательных ограничений формата и безопасности. При редактировании добавляется инструкция сохранить персонажа.

Асинхронный API принимает prompt клиента без BASE_PROMPT мастерской. Параметр style необязателен. Для malevich используется конкретная инструкция, приведённая в API.md. Сюжетная генерация или диалоги отсутствуют.

## Хранение и состояния

Основная SQLite хранит сессии, поколения изображений, работы, лайки и счётчики public/developer. При повторном входе браузер обращается к последней версии. Редактирование сохраняет новую запись, не заменяя предыдущую.

Внешняя интеграция использует другую БД с собственным счётчиком quest. Рабочие состояния queued, processing, completed, failed. Выполняется одна задача за раз в одном процессе; очередь ограничена, изображение имеет TTL. Задача processing после перезапуска завершается с ошибкой, чтобы не повторять возможный платный вызов.

## Подготовка публичной копии

Создана новая история Git. Не перенесены .env, production-базы, логи, сессии, настоящие изображения и пользовательские данные. Публичные примеры используют синтетические ники.

Переоформлены название, графический знак, иллюстрация и палитра. Внешние шрифты и исходные брендовые изображения не поставляются. Добавлены безопасный launcher и изолированные режимы demo/connected, воспроизводимый capture, документация, проверка состава файлов и CI.

Исходники приложения предоставлены владельцем для публикации. Отдельно проверены состав зависимостей и отсутствие включённых сторонних брендовых активов. Это техническая проверка состава, а не независимое юридическое заключение о правах. Открытая лицензия не добавлялась.

## Ограничения проверки

В рамках подготовки публичной версии не выполнялись платные AI-запросы, нагрузочные испытания и публичное развёртывание. Качество реальных изображений, текущая доступность моделей и задержки Quanteex здесь не измерены. В демонстрации нет выдачи тестовых иллюстраций за реальный результат нейросети.
