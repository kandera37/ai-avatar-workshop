# Безопасность

## Безопасный запуск

По умолчанию сервер слушает только 127.0.0.1 и принудительно использует mock-адаптер. Переданные из окружения ключи AI/QUEST в demo-режиме удаляются до загрузки приложения. Реальный провайдер включается только через APP_MODE=connected и ALLOW_PAID_IMAGE_API=1. Платные лимиты новой конфигурации равны нулю.

Все секреты должны оставаться в локальном .env или в защищённом окружении. Не добавляйте ключ в URL, исходники, браузерный JavaScript или обращения к интеграции с клиентской страницы.

Код ведущего генерируется случайно в .runtime/admin-code.txt. На POSIX каталог создаётся с режимом 0700, файлы — 0600; на Windows применяются разрешения вашей учётной записи. После входа используется HttpOnly cookie с ограниченным сроком действия. Внешний HTTPS необходим для Secure cookie. Все административные действия требуют серверной проверки авторизации. Демо-коды в тестах принадлежат только изолированным fixtures.

## Контроль расходов

Три независимых счётчика сохраняются в SQLite. Условный UPDATE резервирует каждую попытку непосредственно перед HTTP-запросом. Редактирование и fallback тоже резервируют единицу. После отправки нет автоматического возврата расхода: невозможно достоверно установить тарификацию провайдера.

Не удаляйте .runtime с рабочими бюджетами. Не запускайте несколько процессов приложения с независимыми БД для одного общего бюджета. Ограничения IP/сессии и circuit breaker находятся в памяти процесса; кластерный режим не подготовлен.

## Данные и ограничения

- Сессия участника — случайный идентификатор в localStorage. Это не полноценная система аккаунтов.
- Публичная галерея не возвращает prompt или административный код.
- Исходные описания, версии и изображения доступны ведущему; учитывайте это до ввода данных.
- Проверки описаний эвристические. Не вводите реальные имена, телефоны и чувствительные сведения.
- SVG доступен только локальному fixture; внешний провайдер должен возвращать растровые данные.
- Публичные изображения интеграции доступны по непрогнозируемому URL без Bearer до истечения срока. Не используйте API для конфиденциальных изображений.
- При перезапуске выполнявшаяся задача интеграции получает JOB_INTERRUPTED, без автоматического повторного платного запроса.

## Перед внешним развёртыванием

Настройте HTTPS reverse proxy, ограничение размеров запросов, доступ к конфигурации, резервное копирование БД и мониторинг бюджета. Пересмотрите допустимый контент, правила приватности и хранение детских данных для своей среды. В репозитории нет production-конфигурации и обещания готовности к любым нагрузкам.

Не публикуйте уязвимость вместе с ключами или пользовательскими данными. В публичном issue достаточно описания воспроизведения на синтетических данных.
